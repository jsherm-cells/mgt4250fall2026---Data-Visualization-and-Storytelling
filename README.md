# MGT4250: Data Visualization and Storytelling

This repository contains course materials and a small Streamlit-based data visualization project for MGT4250: Data Visualization and Storytelling.

## About the project

The repository includes a sample Superstore dataset and a simple Python app that can be used to explore data visually with `streamlit`, `pandas`, and `plotly`.

## Repository contents

- `class17.py` — sample Streamlit app
- `requirements.txt` — Python dependencies for the project
- `sample_-_superstore.xls` — sample business dataset used for visualization exercises
- `README.md` — this project overview

## Setup

1. Create and activate a virtual environment:

```bash
python -m venv .venv
source .venv/bin/activate
```

On Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

2. Install dependencies:

```bash
pip install -r requirements.txt
```

## Run the app

```bash
streamlit run class17.py
```
